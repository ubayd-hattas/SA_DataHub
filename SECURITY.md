# Security

SA Data Hub is a static site with no user accounts and no database in production, so there is little to attack. If you find a security problem, such as a way to change what the site shows or to run code on it, please email uhattas@gmail.com rather than opening a public issue. You will get a reply within a week.

For wrong figures, use the [error report form](https://github.com/ubayd-hattas/SA_DataHub/issues/new?template=error-report.yml) instead.
